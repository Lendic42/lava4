# Практическая работа 4 — типы данных и деление

Учебная программа на C для практики ввода символов и чисел, преобразования типов, работы с цифрами числа и логическим условием.

## Что делает программа

- Показывает примеры типов **char**, **int**, **float** и **double**.
- Читает символ и числа с клавиатуры.
- Разделяет вещественное число на целую и дробную части.
- Печатает числовой код символа в десятичном и шестнадцатеричном виде.
- Сравнивает целочисленное и вещественное деление.
- Находит цифры, сумму цифр и число наоборот для трёхзначного числа.
- Проверяет условие домашнего задания.

## Главный пример деления

В коде заданы **a = 11** и **b = 3**. При делении двух целых чисел дробная часть отбрасывается:

```c
11 / 3
```

Поэтому результат равен 3. Если сначала преобразовать одно число к **float** или **double**, получится примерно 3.666667.

## Трёхзначное число

Введи положительное трёхзначное число, например **123**. Программа найдёт последнюю цифру 3, первую цифру 1, сумму цифр 6 и число наоборот 321.

## Домашнее задание — вариант 27

В таблице домашней работы 20 вариантов, поэтому вариант 27 по кругу соответствует варианту 7. Новый пароль действует, если ровно одно из чисел A и B чётное.

| Ввод | Результат | Почему |
| --- | ---: | --- |
| 4 7 | 1 | Одно число чётное, другое нечётное |
| 4 8 | 0 | Оба числа чётные |

## Как вводить данные

Программа последовательно попросит:

1. Один символ, например **A**.
2. Целое число **i**, например **2**.
3. Вещественное число для **float**, например **12.75**.
4. Вещественное число для **double**, например **0.000000000005**.
5. Положительное трёхзначное число, например **123**.
6. Два числа для домашнего задания, например **4 7**.

Для вычисления 1 / i введи **i**, не равное нулю.
